# ep_report_generator

## Описание модуля

* **additional_tests** - папка с дополнительными тестами.
* **doc** - папка с описанием модуля.
* **report_generator** - папка с модулем.
    * **locales** - папка с файлом перевода на английский язык. 
    * **definitions.py** - файл с классами-перечислениями для типов пинов, типов отчетов.
    * **logger.py** - файл с функциями логирования.
    * **plot.py** - файл с функциями рисования.
    * **reportgenerator.py** - файл с классом **ReportGenerator**.
    * **translation.py** - файл с функцией установки перевода на английский язык.
    * **utils.py** - файл с разными полезными функциями.
* **report_templates** - папка с шаблонами для отчетов.
* **scripts** - папка со скриптами для установки необходимых зависимостей в виртуальное окружение и запуска примеров.
* **tests** - тесты.
* **example.py** - файл с примером создания отчетов.

## Раскрашивание пинов

Пины раскрашиваются следующим образом:

- пин, в котором нет опорной и тестовой сигнатур <span style="color:#FF00FF">(RGB = 255;0;255)</span>.
- пин, в котором есть только опорная сигнатура, похожая на разрыв <span style="color:#FFA500">(RGB = 255;165;0)</span>.
- пин, в котором есть только опорная сигнатура, непохожая на разрыв <span style="color:#0000FF">(RGB = 0;0;255)</span>.
- пин, в котором тестовая сигнатура совпадает с опорной <span style="color:#00FF00">(RGB = 0;255;0)</span>.
- пин, в котором тестовая сигнатура не совпадает с опорной <span style="color:#FF0000">(RGB = 255;0;0)</span>.
